# 폴앤다니엘기독학교 홈페이지

충청남도 아산, 초·중·고 통합 기숙형 기독학교 **폴앤다니엘기독학교(PDCS)**의 새 홈페이지입니다.
빌드 도구 없이 동작하는 정적 사이트라, 파일을 열면 바로 보입니다.

## 페이지

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 — 히어로, 세 기둥, 하루 일과, 교육과정, 갤러리, 공지, 오시는 길 |
| `about.html` | 학교소개 — 인사말, 신앙고백, 교육철학, 섬기는 분들 |
| `admission.html` | 입학 · 문의 — 입학 절차, 상담 신청 양식, FAQ |

## 구조

```
index.html / about.html / admission.html
assets/
  css/style.css              모든 스타일 (CSS 변수로 색상 관리)
  js/main.js                 모바일 메뉴, 스크롤 등장, 숫자 카운트업
  fonts/PretendardVariable.woff2
  img/                       학교 사진, 엠블럼
```

## 미리 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://` 로 열어도 대부분 동작하지만, 웹폰트는 로컬 서버에서 봐야 제대로 적용됩니다.

## 만들어진 방식

- **반응형** — 1280 / 1080 / 860 / 520px 기준으로 레이아웃이 바뀝니다. 모바일에서는 하단에 전화·상담 버튼이 고정됩니다
- **접근성** — 본문 바로가기, 키보드 포커스 표시, 아이콘 버튼 `aria-label`, 터치 영역 최소 46px
- **동작 줄이기 존중** — 기기 설정에서 '동작 줄이기'를 켠 분에게는 모든 애니메이션이 꺼집니다
- **웹폰트 자체 호스팅** — 외부 CDN에 의존하지 않습니다

## 서버 없이 동작하는 방식

이 사이트는 **GitHub 저장소와 GitHub Pages만으로** 돌아갑니다. 서버도, 데이터베이스도, 빌드 도구도 없습니다.

- **상담 신청** — 입력한 내용을 문자(휴대전화) 또는 메일(컴퓨터)로 자동 작성해 열어 줍니다.
  학부모는 보내기만 누르면 되고, 학교는 평소 쓰던 문자·메일로 받습니다
- **지도** — 구글지도 iframe. API 키가 필요 없습니다. 카카오맵 길찾기 링크도 함께 둡니다
- **공지사항** — `index.html`의 카드를 직접 고칩니다. 고쳐서 push 하면 몇 분 안에 반영됩니다

## 아직 비어 있는 것

`［ ］`로 표시된 자리는 학교 자료를 받아 채웁니다.

- 교장 사진
- 드론 항공 사진 또는 영상 (히어로 배경 교체용)
- 방패형 로고 파일 (현재는 원형 엠블럼 사용)
- 유튜브 채널 주소
- FAQ 답변 — **학력 인정 여부는 반드시 학교 확인 후 정확히 표기**
